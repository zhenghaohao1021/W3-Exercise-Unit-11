# W3 Unit 11 — SvelteKit Server Code

A Svelte project downloaded from Telebort Notes.

## Run it on your computer

1. Install Node.js (version 20 or newer) from https://nodejs.org.
2. Open a terminal in this folder.
3. Run: `npm install && npm run dev`
4. Open the address it prints (usually http://localhost:5173).

The files are exactly what you wrote in Telebort Notes. The notes editor only had Svelte and your own files and a few
packages to work with, so a package your code imports that is not in `package.json` may need adding before it runs here.
